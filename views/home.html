Encoding and Decoding

Encoding changes the text entered in the text box to the binary form that means only 1 and 0, Decoding changes the binary(encoded) text into a readable text or the original text

Encrypting and Decrypting

Encrypting encrypt your data to make it more secure it can be used to hide important stuff like addresses etc, Decrypting it turns the encrypted text into readable or original text
